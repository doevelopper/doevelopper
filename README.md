## About Me

I've spent close to two decades designing realtime and safety-critical embedded systems, the kind where timing, correctness, and security aren't negotiable. Over that time I've led Software Engineering teams across multiple companies and engineering plants, building organizations that ship reliable software under real constraints. Today I wear two hats: Engineering Software Manager and Cybersecurity Champion for the software team, bridging strategy and delivery on one side, and secure-by-design practice on the other. Despite the management responsibilities, I stay hands-on, writing code and keeping close to the toolchain, because I believe good leadership in engineering starts with staying technically credible. My focus is industrial and embedded software where safety, reliability, and security have to coexist by design, not by afterthought.

## What I do day-to-day

- Lead and grow software engineering teams across multiple sites and plants, running delivery through Agile frameworks (Scrum / Kanban)
- Champion secure-by-design practices and threat modelling across the software org
- Write and review code to stay close to real implementation challenges
- Bridge safety-critical requirements (IEC 61508 / ISO 26262) with practical delivery
- Mentor engineers and coordinate cross-plant technical alignment
